# 🎓 AI Career Roadmap Generator

## 📌 Project Description

AI Career Roadmap Generator is an AI-based application that helps students create a personalized career roadmap based on their education, current skills, career interests, experience level, study time, and career goals.

The application uses **Streamlit** for the user interface and **LangChain with Ollama** to generate career recommendations and learning roadmaps.

---

## 🎯 Objective

The main objective of this project is to help students:

- Choose a suitable career path
- Identify the skills they need to learn
- Create a step-by-step learning roadmap
- Find suitable project ideas
- Understand possible job roles
- Plan their learning based on available study time

---
